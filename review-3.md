# ¿Qué es mi producto y para qué sirve?

Mi producto es un servidor de lista de tareas, diseñado para ayudarme a organizar y gestionar mis tareas diarias de manera eficiente. Con esta herramienta, puedo crear, actualizar y eliminar tareas, así como establecer prioridades y fechas de vencimiento para mantenerme al día con mis responsabilidades.

# ¿Cuáles son las funcionalidades más importantes y por qué las usaría?

- **Creación de tareas:** Me permite añadir nuevas tareas fácilmente, asegurando que no olvide ninguna actividad importante.
- **Actualización de tareas:** Puedo modificar las tareas existentes para reflejar cambios en mis prioridades o detalles.
- **Eliminación de tareas:** Facilita la eliminación de tareas completadas o que ya no son relevantes, manteniendo mi lista de tareas limpia y organizada.
- **Establecimiento de prioridades:** Puedo asignar niveles de prioridad a mis tareas, ayudándome a enfocarme en lo más importante primero.
- **Fechas de vencimiento:** Me permite establecer fechas límite para mis tareas, ayudándome a gestionar mi tiempo de manera efectiva.

# ¿Qué tecnologías usé y por qué?

Para el desarrollo de este servidor de lista de tareas, utilicé las siguientes tecnologías:

- **Node.js:** Elegí Node.js por su eficiencia y capacidad para manejar múltiples solicitudes simultáneamente, lo que es ideal para aplicaciones en tiempo real.
- **Express.js:** Utilicé Express.js como framework para simplificar la creación de rutas y la gestión de solicitudes HTTP, facilitando el desarrollo del servidor.
- **React:** Para la interfaz de usuario, utilicé React por su capacidad para crear interfaces dinámicas y responsivas, mejorando la experiencia del usuario.

Estas tecnologías me permitieron crear un producto robusto, eficiente y fácil de usar, que satisface mis necesidades de manera efectiva.
